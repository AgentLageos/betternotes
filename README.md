# BetterNotes

A small hand-writing application for note management, focusing on usability and customization.

## Features (planned/integrated)
- **Editor**: A document editor with support for various page types.
- **File Manager**: Organize your notes in folders and move them as you wish.
- **Localization**: Multi-language support (i18n). Currently only German and English.
- **Cross-Platform**: Can be run on any Platform.

## Installation

1. Make sure you have [Flutter](https://docs.flutter.dev/get-started/install) installed.
2. Clone the repository:
   ```bash
   git clone https://github.com/AgentLageos/betternotes.git
   ```
3. Install dependencies:
   ```bash
   flutter pub get
   ```
4. Run the app:
   ```bash
   flutter run
   ```

## Libraries Used
This project utilizes several open-source packages, including:
- [Flutter Riverpod](https://pub.dev/packages/flutter_riverpod) - State Management
- [GoRouter](https://pub.dev/packages/go_router) - Navigation & Routing
- [Shared Preferences](https://pub.dev/packages/shared_preferences) - Local data storage
- [Path Provider](https://pub.dev/packages/path_provider) - File path management
- [File Picker](https://pub.dev/packages/file_picker) - File selection
- [Permission Handler](https://pub.dev/packages/permission_handler) - Permission management
- [Intl](https://pub.dev/packages/intl) - Localization

A full list of all licenses can be found within the app under **Settings > About > Open Source Licenses**.
